POLICY / 01

Privacy

Your health export is processed entirely in your browser. The file contents are not sent to us, an analytics service, or any other server.

What stays on your device

Uploaded CSV and XML data is held in the current page’s memory only. Closing or refreshing the page clears it. The downloaded files go wherever your browser normally saves downloads.

What is stored

The app stores only your timestamp-precision preference in browser IndexedDB and caches the application shell so it works offline. It does not store health records, filenames, date ranges, or selected record types. You can clear this from your browser’s site-data settings.

Network activity

The app makes no runtime request for fonts, scripts, analytics, advertising, or health processing. Your browser requests the static application files from the site host. Standard server access logs may include an IP address, time, requested path, and browser user agent for security and operations.

Sharing risk

Cleaning minimizes a file; it does not anonymize it. The output can still reveal or identify a person. Review it before sharing. We cannot control what a recipient does with a file you choose to send.

Contact and changes

Questions can be raised through the project’s public source repository. Material changes will be reflected here with a new effective date.

Effective: 28 August 2026.
